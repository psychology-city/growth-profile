# 个人成长名片测评系统

基于积极心理学的全维度优势测评工具，帮你发现独特优势、追踪成长轨迹。

## 🌟 功能特点

- **27项核心能力测评**：覆盖认知、人际、意志、超越动力、领导力五大维度
- **五维雷达图可视化**：直观展示个人优势结构
- **成长轨迹追踪**：支持多次测评对比，见证个人成长
- **本地存储**：数据仅保存在浏览器，隐私安全
- **响应式设计**：完美适配手机、平板、电脑
- **深色模式**：支持护眼深色主题

## 🚀 快速开始

### 本地预览

直接用浏览器打开 `index.html` 文件即可使用：

```bash
# Windows
双击 index.html 文件

# macOS
open index.html

# Linux
xdg-open index.html
```

### 部署到 GitHub Pages

1. **创建 GitHub 仓库**
   - 登录 GitHub，点击右上角 `+` → `New repository`
   - 仓库名称填写 `growth-profile`（或你喜欢的名称）
   - 选择 `Public` 公开仓库
   - 点击 `Create repository`

2. **推送代码到仓库**
   ```bash
   # 进入项目文件夹
   cd growth-profile
   
   # 初始化 Git
   git init
   
   # 添加所有文件
   git add .
   
   # 提交
   git commit -m "Initial commit: 个人成长名片测评系统"
   
   # 添加远程仓库（替换 YOUR_USERNAME 为你的 GitHub 用户名）
   git remote add origin https://github.com/YOUR_USERNAME/growth-profile.git
   
   # 推送
   git push -u origin main
   ```

3. **启用 GitHub Pages**
   - 在仓库页面点击 `Settings`
   - 左侧菜单选择 `Pages`
   - Source 选择 `Deploy from a branch`
   - Branch 选择 `main`，文件夹选择 `/ (root)`
   - 点击 `Save`
   - 等待 1-2 分钟，你的网站就会上线！
   - 访问地址：`https://YOUR_USERNAME.github.io/growth-profile`

## 💡 使用建议

- **测评频率**：建议每3-6个月复测一次
- **复测优势**：多次测评数据独立存储，可对比成长变化
- **数据备份**：清理浏览器缓存会删除数据，建议定期截图保存

## 🔒 隐私说明

- 所有数据仅存储在您的浏览器本地（localStorage）
- 数据不会上传到任何服务器
- 清理浏览器缓存或换设备会导致数据丢失
